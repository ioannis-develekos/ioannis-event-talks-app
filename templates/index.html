Local AI Setup Guide (Ollama)

This app runs 100% locally using Ollama and Google's Gemma 4 model with zero subscription or token cost.

1
Install Ollama (Linux / Mac)
curl -fsSL https://ollama.com/install.sh | sh
2
Pull Gemma 4 (26B)
ollama pull gemma4:26b
Or for a lightweight model: ollama pull gemma2:2b
3
Start the Ollama Server
ollama serve
